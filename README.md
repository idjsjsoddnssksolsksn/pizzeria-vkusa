# Пиццерия Вкуса — сайт заказов

Готовый проект: меню, корзина, количество, пожелания к блюдам, данные доставки, оплата и отправка оплаченного заказа администратору в Telegram.

## Быстрый запуск

1. Установите Node.js 18+.
2. Скопируйте `.env.example` в `.env`.
3. Для теста оставьте `DEMO_MODE=true`.
4. Запустите:

```bash
npm start
```

Откройте `http://localhost:3000`.

## Реальная ЮKassa

В `.env`:

```env
BASE_URL=https://ваш-домен.ru
DEMO_MODE=false
YOOKASSA_SHOP_ID=ваш_shop_id
YOOKASSA_SECRET_KEY=ваш_секретный_ключ
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=id_администратора_или_группы
```

В кабинете ЮKassa настройте HTTP-уведомление `payment.succeeded` на:

`https://ваш-домен.ru/api/yookassa-webhook`

Нужен HTTPS. После webhook сервер дополнительно получает платёж по API ЮKassa и сверяет статус и сумму, и только после этого отправляет заказ в Telegram.

## Важно

- Секретный ключ ЮKassa и токен Telegram находятся только на сервере, не в браузере.
- Карточные данные сайт не хранит: клиент оплачивает на стороне ЮKassa.
- `orders.json` подходит для небольшой демо/первой версии. Для полноценного бизнеса лучше заменить на БД.
